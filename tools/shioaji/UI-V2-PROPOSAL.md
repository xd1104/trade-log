## 一、這一版的結構

右欄從「三張疊在一起的卡」改成 **兩個分頁，每一區自己完整**：

```
┌ 跨分頁警報（有真實部位且出事時才出現，兩個分頁都看得到）────┐
├───────────────┬───────────────────────┤
│   練習        │   真實  (+38)          │  ← 頁籤。選中的那一塊是實心的
├───────────────┴───────────────────────┤
│ ▍ 練習下單 ＋ 今天的練習交易 ＋ 練習成績                │  ← 灰
│ ▍ 或                                                     │
│ ▍ 真實下單 ＋ 今天的真實交易 ＋ 版本指紋                │  ← 金
└───────────────────────────────────────┘
```

### 「一眼看得出站在哪一區」＝四個訊號同時變，沒有一個需要讀字

| 訊號 | 練習 | 真實 |
|---|---|---|
| **① 頁籤填色** | 深灰實心 `#1C222C` | **金色實心** `#E3A951`（深字） |
| **② 整區外框** | 扁的、淺邊、沒有陰影 | **金線外框 ＋ 陰影**（全頁最重） |
| **③ 左緣直帶**（4px，貫穿整區高度） | 灰 `--ghost` | **金色漸層** |
| **④ 下單鈕形狀** | **描邊＋淡底**（現況那種） | **實心方向色** |

> 為什麼要四個而不是一個：顏色訊號在餘光裡最弱（他不會每次都正眼看頁籤），
> **形狀（實心 vs 描邊）在餘光裡最強**。四個一起變，任何一個角度掃過去都認得出來。

### 這個結構本身就是防呆

站在練習分頁時，畫面上**根本沒有真實下單鈕**（demo 實測：`document.querySelectorAll('[data-fire]').length === 0`）。
兩組紅綠鈕不會同時存在 —— 這比「靠顏色分辨」強得多，是**結構上的**防誤按。

## 二、真實部位不會因為切到練習分頁就消失（PM 定的那條，已全部做進 demo）

停損活在這台電腦的 Python 迴圈裡。他停在練習分頁的時候，真錢那一邊照樣要看得到：

1. **跨分頁警報**：`報價中斷` 與 `停利沒掛上` 兩種橫幅**畫在頁籤之上**，
   不管站在哪一區都會出現，並附一顆「**去看部位 →**」直接跳過去。
   （demo 實測：站在練習分頁時 `.n-x.bad` 存在。）
   橫幅是 `position:sticky`，右欄捲下去也跟著。
2. **真實頁籤帶標記**：沒站在真實分頁而真實有部位時，頁籤右上角掛一顆藥丸：
   - 正常 → **直接顯示浮動點數**（`+38` 紅／`-24` 綠），連「賺還賠」都不用點進去看；
   - 出事（斷線／停利沒掛上）→ 變成**紅色的 `!`**。
3. **頂列連線燈**照舊會閃（它是獨立節點、不隨報價重繪，是全頁唯一可以安全掛動畫的地方）。

### ⚠️ 要你決定：有真實部位時，要不要自動切到真實分頁？

| | 方案 | 代價 |
|---|---|---|
| **A** ⭐ | **不自動切**，只靠上面那三個標記（頁籤浮動點數／跨分頁橫幅／頂列燈） | 推薦。你正在練習時畫面不會被搶走；代價是「進場成功」那一刻要自己點過去 |
| B | **只在「出事」時自動切**（斷線、停利沒掛上），平常不切 | 折衷。但自動切會打斷你當下在做的事，而橫幅本來就已經在最上面了 |
| C | 一有真實部位就自動切過去，切完鎖住不讓切回練習 | 最安全但最粗暴；真的抱單一整個早上就完全不能練習了 |

**我推薦 A**，理由是「被搶走畫面」本身也是一種傷害，而 B/C 想解的問題（沒注意到）已經被
跨分頁橫幅＋頁籤浮動點數解掉了。但這件事是關於真錢的，我不自己決定，請你挑。

## 三、現況哪裡醜、為什麼（第一版的診斷，依然成立）

數字都是我自己在瀏覽器量的（1500px 寬、右欄 388px）；對比度用 WCAG 公式算，計算腳本我自己跑過。

### A. 層級與誤按

| # | 症狀 | 實測 | 病在哪 |
|---|---|---|---|
| **A1** | **假錢的字比真錢大**：練習浮動點數 `.pnl .v` 44px，真實部位 `.rpos .big` **34px** | 44 vs 34 | 全頁最大的損益數字是模擬的 |
| **A2** | 真實下單卡排在練習下單**底下** | 練習卡 y=27.8、真實卡 y=263 | 順序沒跟著「今天在做什麼」走 |
| **A3** | 有真實部位時，練習的做多／做空還在上面亮著 | — | 同時兩組下單入口，上面那組是假的 |
| **B1** | **誤按防線只寫在註解裡**：CSS 註解說「刻意跟練習長得不一樣」，實作沒做到 | 兩者 `background` 都是 `rgba(238,90,84,.15)`、`border` 都是 `rgba(238,90,84,.38)`、圓角都 12px；真的那顆字**還比較小**（14.5 vs 15.5px） | 靠高度差 19px 分辨真假錢 |
| **B2** | 停利／停損數字 `opacity:0`，**按住才長出來** | — | 決定要不要按的那一刻看不到會掛在哪 |

→ **分頁把 A2/A3/B1 一次解掉**（兩組按鈕不會同時存在），A1/B2 在真實分頁裡另外修。

### C. 顏色一色兩義（08-25 才剛修掉金色的同一個病）

- **C1** 同一張持倉卡裡，`+38` 的紅是「**賺**」，「由面板監控」「沒掛上！」的紅是「**危險**」。
- **C2** **「立刻平倉」是綠色的**（實測 `color: rgb(52,179,126)`、`background: rgba(52,179,126,.15)`）。
  綠＝跌／賣，但**做空的平倉送出去的是「買進」**——09-01 剛出過「平倉送錯邊、變成再加一口空單」的事故。

### D. 最該讀的字是全卡最看不見的字

`--faint`(#5C6472) 在真實卡的底（`--raise` #1A212B）上，實測 **2.72:1**（AA 小字要 4.5:1；`--dim` 是 5.37:1）。
掛在這個顏色上的是：**擋單原因**、**「已掛在券商」**（賺的那邊有沒有保護）、配額、版本指紋、成績單的時間與理由。

### E. 警報做錯兩件事

- **E1 位置**：`.ralarm` 在持倉卡**最底下**、在平倉鈕下面。順序是「浮動點數 → 進場價 → 停利 → 停損 → 平倉鈕 → **停損現在沒人在看**」。
- **E2 它在抖不是在呼吸**：`.ralarm.bad{animation:kk-puls 1.1s infinite}`，但這張卡每 0.5 秒重繪一次（浮動點數跟著報價跳、秒數每秒變）⇒ 整塊 innerHTML 被換掉 ⇒ **動畫每次從頭開始，1.1 秒的呼吸永遠演不完半個循環**。同時違反「每 0.5 秒重繪的東西不准掛動畫」。
  （demo 切到「現況 + 報價中斷」可以直接看到。）
- **E3** 「停利沒掛上」用 `alert()` 講（`alert` 會把整頁 JS 卡死），按掉之後只剩一行 12.5px 紅字。

### F. 成績單

- **F1 欄位不對齊**：`.rtrow` 是純 flex、沒有固定欄寬。拿今天實際的 7 筆量：**時間欄 79.2~125.4px、理由欄 22~66px** 之間跳。
- **F2**（你已修）沒有 `max-height` ⇒ 卡片被撐到 580.2px、右欄 1259.9px。
- **F3/F4/F5**（你已修）「有一筆」寫死、合計筆數說法、內部代號印到畫面。

### G. 配額與版本指紋擠在同一行
「今天真實進場 3 / 3」（**會擋掉下單的硬限制**）跟「程式 09-01 13:47　啟動 13:52」（除錯指紋）同字級同顏色同一行，而且滿額時完全沒有變化。

### H. 真實部位在 K 線圖上完全看不到
`chartSVG()` 畫的是 `s.position`（**練習**部位）的停利／停損橫線；真實部位在 `s.real.position`，**一條線都沒畫**。
→ **假單在圖上有標記，真單沒有。**

## 四、每一條在新結構裡怎麼解

### 真實分頁

1. **浮動點數 34px → 52px**（跟報價區大字同級），底下補「+NT$380 浮動」。（解 A1）
2. **下單鈕改實心 ＋ 停利停損常駐顯示**；按住時整顆鈕蓋一層「**放開取消**」＋底部 0.65 秒進度條；底下常駐「按住 0.65 秒送出・中途放開就取消」。（解 B1/B2）
3. **顏色分工寫死**（解 C1）：
   > **紅綠只描述錢**（漲跌／賺賠）。**系統狀態一律中性灰階＋填滿程度。**
   > 只有「**需要你立刻動手**」才准用**實心紅底深色字的橫幅** —— 形狀跟「紅色的數字」完全不同，不會被讀成「賺」。
   停利／停損改成兩條**保護狀態列**，各帶一顆中性狀態燈：
   ● 實心白＝掛在券商（電腦關機也有效）／○ 空心灰＝這台電腦在看（正常，不是警告）／● 紅＝沒掛上或監控不到（唯一會紅的情況）。
4. **平倉鈕改中性底**，鈕上直接寫「**會送出 買進 ×1（回補空單）**」。（解 C2，直接對到 09-01 的事故）
5. **警報升到最上面（跨分頁）＋ 拿掉 CSS 動畫**；「動」交給頂列那顆不被重繪的燈。「停利沒掛上」從一次性 alert 改成**不會消失的橫幅**＋停利那一列同時標成「沒掛上」。（解 E1/E2/E3）
6. **說明文字的顏色下限**（解 D）：
   > 會影響他決定的字，**最低只能用 `--dim`（5.37:1）**；`--faint`（2.72:1）只准留給純除錯、不影響決定的東西（版本指紋）。
   擋單原因升級成有底色的說明區（12.5px `--dim`），寫清楚**為什麼**與**什麼時候解開**。
7. **配額做成 3 顆點**＋「今天進場 2 / 3」，滿額時整條升級成擋單說明；**版本指紋降到整區最底**、10.5px、只有 `stale` 時變金。（解 G）
8. **成績單固定五欄** `18px 92px 1fr 68px 58px`，理由欄不換行、超出用 `…`；`max-height` ＋ `overflow-y:auto` ＋ 每列 `flex:none`（鐵律 6）；排序**新的在上面**。（解 F1）
9. **真實部位畫到 K 線圖上**：進場價（白）、停利（紅）、停損（綠）三條虛線＋左側掛牌。
   圖是兩個分頁共用的，所以**站在練習分頁也看得到那三條線**。（解 H）

### 練習分頁

10. 結構跟真實那一區**對稱**：下單區 → 今天的練習交易（同一套固定欄表格）→ 練習成績（勝率／合計／勝敗條，維持 08-25 的樣子）。
11. 下單維持**單擊**（練習不需要長按防呆），按鈕維持**描邊＋淡底**——那是它跟真實區在形狀上的分界，**不要改成實心**。
12. 休市時兩區都真的 `disabled` ＋ 寫清楚原因（12.5px `--dim`）。這是紀錄正確性，不是 UX 取捨。

## 五、給 dev 的兩條硬規則（demo 施工時真的踩到）

### ⚠️ 1. 新元件的修飾字不可以裸寫 `.real` / `.sim`

`live_panel.py` 已經有 `.real{margin-top:14px; background:linear-gradient(...); border-color:var(--gold-line)}`。
我第一版把頁籤寫成 `class="n-tab real"` ⇒ **被既有的 `.real` 套中**：
實測**第二顆頁籤整個往下掉 14px**（sim y=144.8 / real y=158.8，兩顆同高卻不同水平線），
而且未選取時還吃到別人的漸層底。
**修法是加前綴**（`t-real` / `t-sim` / `z-real` / `z-sim` / `c-real` / `c-sim`），
不是去改既有的 `.real` ——那條還在服務現況的卡片。
兩顆頁籤高度**寫死 62px**（改字級要重量一次，不准用字級推算）。

### ⛔ 2. 長按送單期間，含那顆按鈕的節點不准重繪

我做 demo 時忘了加這道守衛，結果**長按 900ms 完全送不出去**——每 0.5 秒的重繪把按鈕換掉了。
`holdingNow` 擋住重繪，計時器裡再加一道 `document.body.contains(el)` 保險。
另外整個右欄要拆成**各自比對自己字串**的節點（跨分頁警報／頁籤／該區的身體／紀錄表／指紋），
比對一律用「上次自己設進去的字串」快取在節點上，**不可以讀回 `innerHTML`**。
