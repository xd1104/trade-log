Python 3.12 venv 在 repo 根目錄 `.venv`，已安裝 shioaji 1.7.2 與 pandas。

### 2. 通過期貨 API 測試
跑 `tools/shioaji/shioaji_futures_test.py`（**模擬模式 simulation=True，不碰真錢、免憑證**）。

- 金鑰見上面 1.5（**由 Benson 自己填，不要幫他把金鑰貼進對話或檔案 commit**）

### 3. 抓歷史 K 線
測試通過後跑 `tools/shioaji/shioaji_export.py`（正式環境、只讀資料、免憑證），
預設拉 `TXF.TXFR1`（台指期近月連續）1 分 K，輸出 `txf_1min.csv`。
建議至少半年～一年，樣本才夠。

### 4. 回測（重點）
用 1 分 K 合成每日開盤首根 5 分 K（09:00–09:05），計算：

- 首根 5 分 K **收紅 vs 收黑** → 接著順勢進場的勝率、平均點數、期望值
- 進一步切分：跳空開高／開低、首根 K 實體大小、有無長上/下影線、
  「突破首根K高/低點才進」vs「收盤價直接進」
- **分時期看**（例如每月），驗證他說的「最近變亂」是規律退化還是行情盤整
- 出場條件先用他實際習慣：**±100 點**（他模擬時多半 100 點停利/停損），可另跑幾組比較

輸出要是**可執行的結論**，例如：「開高＋首根收紅 → 做多，歷史勝率 XX%、期望值 +XX 點／樣本 N 天」。
務必附上樣本數與「歷史不保證未來」的提醒。
